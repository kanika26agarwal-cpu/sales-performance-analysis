# sales-performance-analysis


## 1. Project Overview
This project analyses retail sales data to understand business performance and identify opportunities for growth.

## 2. Business Problem
Management wants to understand sales trends, regional performance, product performance and revenue growth.

## 3. Project Objectives
- Analyse total sales and revenue.
- Identify top-performing products.
- Compare sales across different regions.
- Understand monthly sales trends.
- Identify areas for business improvement.

## 4. Tools Used
- Microsoft Excel
- SQL
- Power BI
- GitHub

## 5. Key Business Questions
1. What is the total revenue?
2. Which product generates the highest sales?
3. Which region performs best?
4. Which month records the highest sales?
5. What recommendations can improve sales performance?

## 6. Expected Deliverables
- Cleaned sales dataset
- SQL queries
- Excel analysis
- Power BI dashboard
- Business analysis report
